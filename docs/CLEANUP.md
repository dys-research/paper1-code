# Cleanup scope

The publication directory reorganizes the supplied research scripts into five
stages with one private configuration file and repository-relative code paths.
The original uploaded archive is preserved separately.

## Retained

- Sample selection, first-independent-claim selection and control preparation.
- The extraction prompt, configurable extraction client, input fingerprints and
  source-span validation.
- Temporal histories, domestic family controls, exact citation windows, source
  embeddings, fixed-window novelty, cited-mechanism anchoring and semantic reuse.
- M1–M6 explanatory specifications, mature-label forecasts, whole-text
  comparisons, fixed-budget screening and paired clustered inference.
- Selected role/source, lexical, anchoring and outcome robustness analyses.
- Optional Kelly-inspired forward/backward diagnostic, four-endpoint prediction
  Holm inference and an explicit original conditional-model sample generator.
- Date-aware internal-link exclusions for historical novelty and subsequent
  semantic reuse, with separate sensitivity fits.

## Removed or consolidated

- One-off old/new sample comparison and legacy-extraction audit scripts.
- Missing-100 batch wrappers, fixed provider batch directories and absolute
  external-script loaders.
- GPU transfer ZIP builders, damaged-download checks, historical acceptance
  receipts and hardcoded checks for one run's file counts and sample totals.
- Incremental CPC repair scripts: the main metadata construction now uses exact
  int64 masks directly.
- Narrative report generators containing dated progress, private local paths or
  prewritten completion claims.
- Duplicate bootstrap/validation wrappers and the stored-output figure notebook.
  Computed model outputs are exposed as reusable CSV/Parquet files.
- Literal credentials, machine-specific drive paths and local runtime injection.

## Changes in execution

Inputs and outputs are configured explicitly. Scripts no longer depend on the
author's earlier processed panel or local acceptance files. Available source
metadata and text are checked before they enter the corresponding calculations.
Missing raw measurements remain missing until model-matrix preprocessing.

The cleanup preserves the core calculation definitions. Parameter settings that
change scientific comparisons must be recorded as new runs. Exact reproduction
still requires upstream normalized data and the original measured inputs. The
repository does not manufacture missing model provenance or human annotations.
